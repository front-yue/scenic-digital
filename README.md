# Fay 智能数字人 - 物联网中控模拟系统 (纯前端 Demo)

本项目是一个 **100% 纯前端模拟、零硬件、可直接演示** 的业务场景 Demo。
非常适合用于：**演示、答辩、投标、客户展示、课程设计**。

通过模拟物联网设备数据与控制指令，结合 Fay 数字人交互逻辑，实现了一个看起来和真的一模一样的数字人智能家居中控系统。

## 🔥 核心功能

- **数字人交互界面**：模拟数字人待机、讲话状态与动画。
- **智能家居中控大屏**：实时展示环境温湿度、各种智能设备（灯光、空调、门锁等）的状态。
- **自然语言解析 (NLP) 模拟**：纯前端实现基于关键词与场景的意图解析，将自然语言转换为设备控制指令。
- **虚拟物联网设备**：响应式的设备状态管理，无缝联动 UI 更新。

## 🚀 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```

## 🎮 可演示对话案例

启动项目后，在左侧输入框中对 Fay 说话：

- **单设备控制**
  - 用户：“打开客厅灯”
  - Fay：“客厅灯已打开啦～” (右侧客厅灯图标点亮)
- **场景模式联动**
  - 用户：“我出门了”
  - Fay：“已为您开启离家模式，祝您一路平安！” (所有灯光空调关闭，门锁锁定)
- **状态查询**
  - 用户：“家里温度多少？”
  - Fay：“当前室内温度 24 度，湿度 46%，非常舒适～”

## 🛠 技术栈

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Tailwind CSS v4
- Lucide Vue Next (图标库)

## 📁 目录结构

- `src/App.vue`: 主页面，包含数字人UI、对话框、模拟NLP解析、设备状态管理。
- `src/components/DeviceCard.vue`: 智能设备展示卡片组件，支持状态切换动画。
